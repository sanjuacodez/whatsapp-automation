Connect in 4 steps

  1. Pick QR scan or phone code from the tabs above.
  2. Pair the WhatsApp account and wait until the connection shows open.
  3. Use Restore webhook if the instance was recreated or the webhook was lost.
  4. Open n8n to manage WooCommerce credentials, workflow logic, and execution history.

What to expect

Refresh behavior

  • When the instance is already connected, Evolution usually stops returning a QR or pairing code.
  • If you need a new pairing method, recreate the instance with the phone number field first.
  • Long webhook URLs are wrapped inside this dashboard so they do not break the layout.
